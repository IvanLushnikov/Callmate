# Callmate

Публичный интерфейс кабинета Callmate.

Это только морда. Серверная логика и внутренняя документация живут в закрытой репе продукта.

## Локальный запуск

Статический каркас (без сборщика):

```bash
cd /Users/ivanlusnikov/Callmate
python3 -m http.server 5173
```

Откройте `http://127.0.0.1:5173/`. Базовый URL API — `window.CALLMATE_API_BASE` или `.env` (см. `.env.example`). Без API работает локальный stub входа (`admin`/`admin` → админка; любой другой логин/пароль → кабинет).
