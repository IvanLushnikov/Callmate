# Scorix

Публичный интерфейс кабинета Scorix.

Это только морда. Серверная логика и внутренняя документация живут в закрытой репе продукта.

## Демо (GitHub Pages)

https://ivanlushnikov.github.io/Scorix/

На своём домене кабинет ожидается по пути `/lk/` (лендинг на `/`). Локально и на GitHub Pages префикс не нужен.

Вход без API (stub):

| Логин | Пароль | Куда |
|---|---|---|
| любой непустой | любой непустой | личный кабинет |
| `locked` | любой | кабинет с баннером «доступ ограничен» |
| `admin` | `admin` | админка |

## Локальный запуск

Статический каркас (без сборщика):

```bash
python3 scripts/dev-server.py 8765
```

Откройте `http://127.0.0.1:8765/`. Dev-сервер проксирует `/api/*` на бэкенд (см. скрипт) — иначе с localhost вход блокирует CORS.

На своём сервере кабинет кладётся в `/lk/`; API на том же домене (`/api`, `/health`). `SCORIX_API_BASE` тогда не нужен — берётся `location.origin` (см. `.env.example`).

Обычный `python3 -m http.server` — только для stub-режима без API.
