# Callmate — smoke checklist (кабинет)

Узкий чеклист для кампаний / контактов / статусов / тарифов.  
**Не входит:** admin «Интеграции», FE-189, backend New.

## Автоматически (Playwright)

```bash
cd /path/to/Callmate
npm install
npx playwright install chromium
npm run test:e2e:smoke
```

Офлайн-stub: API отключён через init-script, данные в `localStorage`.

## Ручной проход (stub или стенд)

1. **Вход** — форма логина, бренд CallMate, поля логин/пароль.
2. **Кампании** (`#/cabinet/campaigns`) — список или empty-state; бейдж статуса; CTA «Создать кампанию».
3. **Workspace** — вкладки Обзор / Контакты / Сценарий / …
4. **Контакты** — upload-зона, таблица, фильтры статусов (Все / В процессе / Завершён / Недозвон / Отмена).
5. **Статусы** — у строки контакта бейдж статуса; фильтр «Завершён» оставляет только done.
6. **Биллинг** (`#/cabinet/tariffs`) — баланс, тариф ₽/мин, таблица пакетов, подсветка текущего пакета.
7. **Антискоуп** — не открывать `#/admin/integrations` в этом прогоне.

## Ожидаемый результат

- Нет белого экрана / необработанных ошибок в консоли на ключевых hash-маршрутах.
- Навигация Кампании ↔ Биллинг работает.
- Фильтр статусов контактов меняет состав таблицы.
