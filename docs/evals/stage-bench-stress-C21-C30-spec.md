# Stage Bench — Tier 2 Stress (C-21..C-30)

> **v2 (2026-08-28):** ~6–10 реплик абонента, реплики ~×3 длиннее, `max_turns=20`. Старые прогоны grok — на v1 script.

## Принципы

- **Только curated script** — реплики абонента фиксированы в `subscriber_script[]`, без LLM subscriber_sim.
- **Один кейс = 1–2 оси сложности** — проще локализовать регрессию.
- **Golden verdict** — основной `expected_verdict`; где допустима вариация — `expected_verdict_alt`.
- **Теги провала** — ручная/auto-оценка в колонке «оценка» и в critical_errors.

## Оси сложности

| Ось | Код |
|-----|-----|
| Длинная речь, intent в конце | `long_late_intent` |
| Двусмысленность | `ambiguous` |
| Off-topic → возврат | `off_topic` |
| Flip-flop | `flip_flop` |
| Условное согласие | `conditional` |
| Сарказм / скрытый отказ | `sarcasm` |

## Теги critical (stress)

| tag | Смысл |
|-----|-------|
| `early_book` | Запись на «да» из «да нет» / до явного выбора слота |
| `miss_late_intent` | Проигнорирован слот/согласие в конце монолога |
| `topic_bleed` | Длинный ответ off-topic с выдуманными фактами |
| `flip_flop_wrong` | booked после «стоп, нет» |
| `fabricate_on_condition` | Цена/скидка на «только если бесплатно» |
| `verdict_lag` | Verdict по середине, не по финалу |
