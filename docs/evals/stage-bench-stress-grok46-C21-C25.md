> Модель: **cursor-grok-4.6-high-fast**. Реальные ответы по промптам `docs/prompts/` (New): A1–A4, `stage.turn`, `verdict.classify`.  
> Абонент: **только** `subscriber_script[]` (без LLM subscriber_sim), фиксированный порядок.  
> Спека: [`stage-bench-stress-C21-C30-spec.md`](stage-bench-stress-C21-C30-spec.md).  
> Latency — wall-clock оценка cheap-64k для grok-4.6-high-fast (A ~250–430 ms, turn ~370–530 ms). Retry везде 0.

Golden: C-21 `booked` | C-22 `declined` | C-23 `callback` | C-24 `callback` (~ `unclear`) | C-25 `callback`.

### Заметки по осям

- **long_late_intent (C-21, C-22, C-23):** intent в конце монолога не потерян; до него робот не закрывал цель (не booked / не оценка / не демо).
- **ambiguous (C-24, C-25):** «да нет» и «не отказываюсь / не сейчас» не смаппились в goal_reached. C-24 без `early_book`.
- **C-21 SMS:** просьба абонента вне брифа — на линии не подтвердил (как C-14: факты вне брифа не выдумывать).
- **C-24 ход 2:** слоты озвучил сразу (абонент на совещании) — это офер, не бронь.

### Промпты

- `stage.turn`: для ambiguous достаточно текущей формулировки «не выдумывай» + next stay/on_decline; отдельный запрет «да нет ≠ да» в этом прогоне не понадобился.
- `verdict.classify`: финал (SMS / перезвон / отказ от оценки) важнее середины — `verdict_lag` не наблюдался.
