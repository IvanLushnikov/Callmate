# Правила для агентов (Scorix)

1. Здесь только UI кабинета и тонкий клиент публичного API.
2. Источник правды по продукту и бэку — закрытая репа штаба (`New`). Не копируй сюда PRD, контракты, бэклог, скиллы штаба.
3. Вход в работу FE — передаточный пакет `docs/handoff/fe/<ID>.md` из штаба. Без пакета UI не выдумывай.
4. Не коммить `.env`, ключи, выгрузки контактов.
5. Не описывай в коде и README закрытую внутренность продукта: секреты телефонии, инструкции для моделей, правила персональных данных, имена внутренних адаптеров, схему хранения.
6. С продактом — простой русский. Просьба «сделай экран / доработай фронт» = правки в коде Scorix, не только заметки.
7. После **коммита и push** — коротко своими словами, что изменилось в кабинете для человека: без номеров задач, веток и технарщины. Не «запушил в main» — а что теперь умеет или стало лучше.
